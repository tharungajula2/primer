Cache Levels Overview

Modern CPU memory hierarchies balance latency, bandwidth, and capacity across L1, L2, L3 caches and main DRAM memory.

Latency and Bandwidth Tradeoffs

Each tier in the hierarchy trades capacity for speed. Accessing main memory takes ~60x longer than reading from L1 data cache.
